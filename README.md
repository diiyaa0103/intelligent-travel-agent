# VoyageMind - Intelligent Travel Planning Agent

## Run

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

The application demonstrates a travel knowledge base, graph representation, BFS, DFS, UCS, Greedy Best-First Search, A*, goal-based planning, utility-based planning, destination constraints, and itinerary generation.

All prices and travel times are illustrative academic estimates.
